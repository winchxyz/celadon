# Sound credits

Every file in this folder is **CC0 1.0 (public domain dedication)**. No
attribution is legally required for any of it; it is recorded here because
knowing where a thing came from is worth more than the licence demands, and
because the next person to touch this folder should be able to check.

Each source page was read and its licence confirmed as CC0 before the file was
taken. Files were converted to mono 24 kHz Ogg Vorbis, and `kiln.ogg` is a six
second excerpt looped with short fades; nothing else was edited.

## What is still synthesised, and why

The clay under your hand is not a recording and should not become one. It has
to answer continuously to how hard you are pressing, how fast the wheel is
turning and how wet the pot is — a recording has one texture and cannot do
that. The same goes for the music. What the recordings replace are the things
that really are fixed sounds: a motor, a fire, a room, a click.

If a file here is missing or will not decode, the game says so in the console
and carries on with the synthesised set. Nothing depends on these being
present.

## Swapping one out

`wheel.ogg` was chosen by measurement rather than by ear — of the eleven
machine loops in that pack it was the most low-dominant and the least shrill
(−26 dB below 400 Hz against −40 dB above 2 kHz), and at 4.5 seconds it is long
enough not to sound obviously looped. If it is wrong, any mono Ogg dropped in
its place under the same name will be picked up; the loops are pitched by
playback rate, so something around a few seconds works best.
